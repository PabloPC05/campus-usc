# campus-usc-core

El **motor** del Campus Virtual de la USC: una biblioteca de Python que sabe hablar con el
Moodle de la USC por HTTP (entrar, leer tareas, entregar, notas, horarios…). **No es un MCP ni
un CLI**: es la pieza de debajo que usan el CLI [`campus`](https://github.com/PabloPC05/campus-usc)
y el servidor [`mcp-usc`](https://github.com/PabloPC05/campus-usc/tree/main/mcp).
